# Demand to Conversation Package

Install this package when the job is to turn a small, owner-selected set of public conversations into one credible contribution and a permissioned next step. It is a focused set, not a lead-generation system and not permission to operate social accounts.

## What this package installs

Install only these four skills, in this order. Download the public `SKILL.md` source for each into the active local skills directory. Do not delete, move, rename, or overwrite unrelated skills.

| Skill | Job in the package | Source |
| --- | --- | --- |
| `signal-to-conversation` | Finds the evidenced problem, one useful contribution direction, proof gap, and owner-approved next step from a 5–15-item public source set. | `https://why57.com/skills/signal-to-conversation/SKILL.md` |
| `proof-library` | Turns owner-approved records into source-linked claim cards before a public claim is made. | `https://why57.com/skills/proof-library/SKILL.md` |
| `social-content-strategy` | Checks the owner’s selected published content for useful patterns, gaps, and one reviewable experiment. | `https://why57.com/skills/social-content-strategy/SKILL.md` |
| `voice-kit` | Builds approved, channel-specific writing rules from the owner’s selected public work. | `https://why57.com/skills/voice-kit/SKILL.md` |

Confirm the installed skill names and paths. If the environment cannot download or save skills, say so plainly and stop. Do not run any skill during installation.

## How the skills work together

1. Start with `signal-to-conversation` and only 5–15 public posts or threads the owner selected. It returns a Demand-to-Conversation Action Packet, including what is observed, what is inferred, what proof is missing, and the owner’s decision.
2. If the packet identifies a claim worth making, use `proof-library` on owner-approved project records. Keep only wording the source, scope, date, and permission support.
3. If a contribution is approved, use `social-content-strategy` on the owner’s selected published work to check the content job, pattern, and gap. Use `voice-kit` only after its writing rules are reviewed and approved.
4. Stop with a reviewable contribution or draft direction. The owner chooses whether to publish, reply, contact anyone, or do nothing.

## First use

Ask the owner for one business result, the target buyer or decision context, one current offer, one permissible next action, 5–15 selected public URLs or pasted items, and one to three approved proof sources. Do not ask for credentials, account access, private messages, a broad scrape, a contact list, or permission to automate engagement.

The useful end state is a source-backed contribution direction and a low-pressure conversation bridge—not a list of people to chase.

## Boundary

The AI may organize the selected evidence, identify uncertainty, prepare proof cards, and draft only after approval. The owner verifies sources and community rules, approves wording, and personally takes any external action. Do not scrape broadly, collect profiles, send messages, publish, schedule, or represent the owner.
