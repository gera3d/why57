# Warm Reconnect Package

Install this package when the job is to reconnect with people you already know, ask for a supportable introduction, or clear a small follow-up queue. It is a relationship-evidence workflow, not a lead list or an inbox automation system.

## What this package installs

Install only these three skills into the active local skills directory. Download the public `SKILL.md` source for each. Do not delete, move, rename, or overwrite unrelated skills.

| Skill | Job in the package | Source |
| --- | --- | --- |
| `relationship-map` | Turns 10–25 owner-selected threads, a narrow authorized label, or a pasted relationship list into a ranked map of evidence, uncertainty, contact flags, and possible next moves. | `https://why57.com/skills/relationship-map/SKILL.md` |
| `outreach-planner` | Turns an owner-approved relationship map and selected facts into a small, reviewable outreach plan with clear no-contact rows. | `https://why57.com/skills/outreach-planner/SKILL.md` |
| `voice-kit` | Builds approved, channel-specific writing rules from the owner’s selected public work before a later draft is considered. | `https://why57.com/skills/voice-kit/SKILL.md` |

Confirm the installed skill names and paths. If the environment cannot download or save skills, say so plainly and stop. Do not run any skill during installation.

## How the skills work together

1. Start with `relationship-map` and a deliberately selected relationship set. It returns a ranked review table with evidence, uncertainty, sensitivity, and rows that should not be contacted.
2. After the owner approves the rows in scope, use `outreach-planner` with a current goal, selected facts, and a clear purpose for each person. It returns a supportable next move or a clear reason to do nothing.
3. Use `voice-kit` only after the owner selects one person, channel, purpose, and approved samples. Its rules can guide one later unsent draft; they do not authorize a message.
4. Stop at the reviewable plan or unsent draft. The owner chooses whether to contact anyone, when, and how.

## First use

Ask for one relationship goal, 10–25 selected threads, one narrow authorized label, or a pasted relationship list; the current reason for contact; selected supporting facts; and the owner who will review every row. If a later draft is needed, also ask for approved writing samples and the intended channel. Do not ask for an inbox dump, credentials, enrichment data, a contact database, inferred intent, or permission to send or schedule.

The useful end state is a short list of next moves that the owner can explain—not a larger contact list.

## Boundary

The AI may organize selected relationship evidence, flag uncertainty, recommend a careful move, and prepare an unsent draft only after the owner chooses the person and purpose. The owner controls inclusion, context, every external message, scheduling, contacts, CRM records, and account changes.
